# 高性价比搞钱指南

> 没时间去研究理财，用最少的钱、时间和心思，换回更多的钱和更稳的生活。

这是「高性价比」系列（饮食 / 睡眠 / 运动 / 搞钱）的第四本。面向没时间研究理财的普通人，按「成本 × 收益 × 证据等级 × 性价比」的框架，把 193 条经过筛选的建议排好序——你不必全做，挑性价比最高的几条就够。

## 这是什么

一本循证取向的搞钱手册。它不教你暴富，也不卖课，而是把「普通人真正能撬动的几件事」——别亏大钱、先保底、砍掉隐性失血、清高息债、指数基金定投、复利、加薪跳槽、避开消费陷阱和骗局——按性价比排成一份备选单。

每一节回答一个具体问题，每条建议写明四件事：

- **成本**：要花多少钱、多少时间、多少毅力（钱 / 时间 / 毅力，各三档）
- **说人话**：用日常语言讲清楚这条能换回什么
- **收益**：收益量级（大 / 中 / 小）+ 口径（换回的是省下的钱、多赚的钱，还是财务安稳）
- **证据等级**：A（荟萃分析 / 随机对照 / 权威数据）、B（有一定支持）、C（共识 / 常识）
- **来源**：论文、监管机构或官方文件，尽量给 DOI / 链接
- **备注**：一句补充或交叉引用

性价比档（极高 / 高 / 一般）由「收益量级 + 三项成本」合成，**与证据等级是两回事**——「一般」不等于不该做，只是它要的成本更高或收益更间接。

## 在线检索页怎么用

在线版（index.html）是个零依赖的单文件阅读页，手机 / 断网都能看。它支持：

- **搜索**：按关键词实时过滤
- **筛选**：按章节、证据等级、性价比，以及「花不花钱 / 花多少时间 / 要不要毅力」逐档筛，可叠加
- **交叉引用**：正文里「第 X 节第 Y 条」可点击跳转
- **明暗主题**与**打印**

想只看最值得做的：勾选性价比「极高」，得到 32 条几乎不花钱、不花时间、不太需要毅力，收益又落在最大一档的条目。

## 证据分级说明

- **A**：荟萃分析 / 随机对照试验 / 权威长期数据（如 SPIVA 报告、雇主匹配养老金的参与率研究、Madrian & Shea 的 401(k) 自动加入研究）
- **B**：有研究或数据支持，但结论有一定条件（如定投降低择时风险、支付痛感研究、薪酬跳槽数据）
- **C**：广泛共识或常识性框架（如 50/30/20、应急金 3–6 个月、先保人再保财）

本书**不构成投资建议**，也不承诺任何收益。所有「回报」「收益率」均为历史数据或演示口径，实际会波动。涉及具体产品、税务与法律，请以你所在地官方口径和专业人士意见为准。

## 性价比口径

拿收益量级（大 / 中 / 小）加上三项成本（钱、时间、毅力），合出一个性价比档：几乎不花什么成本、换回的好处又大的，归为「极高」或「高」；要花不少钱或很多毅力的，归为「一般」。**性价比只代表「投入产出比」，不代表「该不该做」**——有些「一般」的条目（如长期定投、养老账户）之所以值得，是因为它的收益要靠很多年才显现。

## 本地构建

```bash
python build.py            # 生成 index.html（单文件阅读页）
python make_pdf.py -o how-to-earn-better.pdf   # 生成 PDF
```

依赖：`build.py` 零依赖；`make_pdf.py` 需要 `reportlab` 和系统中文字体（Windows 用微软雅黑 / 宋体，Linux 用 Noto CJK / 文泉驿）。CI 会在每次改动 `book/` 后自动重新生成并部署。

## 目录结构

```
book/              16 个章节的 Markdown 正文（NN-标题.md）
build.py           把 book/ 渲染成单文件 HTML 阅读页
make_pdf.py        把 book/ 排版成 A4 PDF（封面 + 目录 + 前言 + 正文 + 书签）
index.html         生成的阅读页（也是 GitHub Pages 入口）
how-to-earn-better.pdf   生成的 PDF
```
